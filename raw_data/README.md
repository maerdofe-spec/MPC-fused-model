# 原始实验数据归档

本目录集中保存实验记录、原始输入和控制实现所需的标定依据。整理日期：2026-09-17。

- `calibration_logs/`：629 个实验与标定文件，包括 CSV、JSONL、rosbag SQLite 数据、袋文件元数据、现场照片、日志及标定结果。控制配置引用的分析 JSON 和外参 YAML 一并保留。
- `inputs/mpc/`、`inputs/smc/`：22 个此前用于 MPC/SMC 对比的原始输入副本。
- `source_figures/`：3 张此前归档的原始参考图，保留作为数据来源材料。
- `INVENTORY.csv`：654 个归档文件的原路径、归档路径、字节数和 SHA-256 校验值。该清单不包含本说明和清单自身。

所有归档文件均按移动前的 SHA-256 逐一核验，文件内容未改动；未对重复记录进行去重。
原有 `calibration_logs/` 路径通过目录连接指向本目录下的同名文件夹，以兼容控制配置和后续日志写入。
控制代码集中到 `control/` 后，`control/calibration_logs/` 同样指向本目录下的同名文件夹，不重复保存数据。
上述连接仅用于本机旧命令兼容，不上传到 GitHub；控制配置和默认实验日志路径直接使用归档目录。
派生绘图、论文、PPT、排版临时文件与绘图工作目录已清理，控制代码、测试、固件及实现文档保留。
